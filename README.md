# 📋 Bihar Matric Result Fetcher

Fetch and export your entire school's Bihar Matric results in one click - no manual entry, no hassle!

## 🚀 Features

- ✅ Auto serial roll numbers (2600001 onwards)
- ✅ Real-time progress tracking
- ✅ Excel export with multiple sheets
- ✅ Pass/fail detection
- ✅ School topper identification
- ✅ Beautiful UI
- ✅ No login required

## 📊 What You Get

- **Results Sheet:** All student marks and details
- **Summary Sheet:** Statistics, pass/fail count, topper info
- **Ready to Download:** Excel file ready in seconds

## 🎥 How to Use

1. Visit the app
2. Enter your school's **Roll Code**
3. Enter **Number of Students**
4. Click **"Fetch Results"**
5. Download Excel file automatically
